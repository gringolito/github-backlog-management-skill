---
name: add-idea
description: >-
  Park a rough idea in the backlog so it isn't lost, without defining, prioritizing or sizing it.
  Use when the user has an idea to come back to later, or asks to note, park or jot one down.
argument-hint: "The idea, in your own words."
---

Capture an idea the user has no time to define yet. When you finish, an issue labeled only
`type:idea` and `needs-clarification` exists in the Project, holds the idea as the user put it, and
sits at the bottom of the Queue.

Capturing should cost the user almost nothing, so don't run discovery, check INVEST or shape the
body. Give it a short title that names the idea, and write the body from the user's words plus any
context they pointed to, such as a link or the problem that prompted it. Don't invent
requirements, scope or acceptance criteria.

The issue carries no priority, effort, milestone or assignee.
