---
name: add-idea
description: >-
  Park a rough idea in the backlog so it isn't lost, without defining, prioritizing or sizing it.
  Use when the user has an idea to come back to later, or asks to note, park or jot one down.
---

Capture an idea the user has no time to define yet. When you finish, an issue labeled only
`type:idea` exists in the Project, holds the idea as the user put it, and sits at the bottom of the
Queue, below every defined item.

Capturing should cost the user almost nothing, so don't run discovery, check INVEST or shape the
body. Ask only when you can't tell from what they said what the idea is about. Give it a short
title that names the idea, and write the body from the user's words plus any context they pointed
to, such as a link or the problem that prompted it. Don't invent requirements, scope or acceptance
criteria.

The issue carries no priority, effort, Milestone or assignee. Those come when `refine-item` turns
the idea into a defined item.

Place it at the bottom of the Queue unless the user names a position. Reply with the issue link.
